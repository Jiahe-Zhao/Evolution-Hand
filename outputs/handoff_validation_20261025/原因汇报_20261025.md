# 灵巧手进化难收敛：代码核对、接续验证与 DERL 参考

## 结论框架

当前不能把失败归为一个原因。至少存在三条独立链路：固定基准手的 PPO 技能退化、父策略跨形态不匹配、部分变异的物理/接口异常。增加算力不能自动消除这些问题。

### 1. 固定基准也退化：首先检查学习接续

上轮基准形态未变，完整回合成功从255/256降至31/256。训练中完整回合成功随后降至4/256。没有记录掉落、明显关节越限或所设严重物理异常；因此它的主要证据是策略改变后不再持续满足稳定保持，而非已经证明接触求解器弹飞。异常阈值未触发不能证明所有物理模型正确。

接续存在已确认的实现问题：旧流程预热 Critic 用3e-4，解冻 Actor 后把 Critic 一并降到约1e-7量级；Critic 更新能力骤降。旧观测没有连续持握时长、手指速度和接触力方向，虽然这些影响奖励或状态演化。固定探索标准差很小，但它只限制采样噪声，不能限制多次 PPO 更新后均值累计偏离。

尚待单项消融确认：以上每个因素对最终退化分别贡献多少。本次校准方案同时改动价值拟合和更新控制，只能判断组合效果。

### 2. 变异后初始成功率低：迁移失败不等于结构差

一些后代在 PPO 更新前就从高成功变为零成功。同一套关节角策略放到不同指长/张角上，不再产生同一接触姿态。当前网络没有显式形态基因输入；继承策略只提供起点，不保证适应。

只用短程继承策略分数评判结构，会偏向与第0代相近的结构。保留“仅第0代BC”可以，但后代需获得足够独立RL预算；最终优胜者应以公平初始化、多seed再检验，避免只选出最兼容旧策略的手。

### 3. 部分变异还有物理或代码问题

finger_spread 后代在训练前就出现约264N接触力、0.483rad关节越限，异常在极早期发生；这优先指向零位/接触/驱动适配问题，具体机制尚未由本次实验定位。不能归咎为PPO探索过大。

thumb_axis+5° 被运行时 `Thumb CMC opposition axis must be +/-Y` 拦截；这是静态基因合法性与运行时硬编码不一致。它不是一个已训练失败的结构。本次未修改手结构或解决该接口限制。

## 本次修正的边界

- 观测67扩展108；新增权重初始为零，保留BC动作函数，后续可学习。
- 不增加BC；所有验证在generation=1，bc_updates=0。
- 保持手、接触参数、任务奖励、完整25秒评估和外部扰动一致。
- 对照：常规128epoch Critic预热，再128epoch Actor PPO。
- 校准：完整随机策略回合拟合Critic；Actor不变；随后独立Critic学习率，更新后KL约束Actor，128epoch Actor PPO。
- 两训练组统一关闭value normalization。因此不能把这次对照视为上轮原配置完全复现。
- 32环境、同一seed；最终评估均值动作。没有独立seed泛化验证，不声称长期收敛。

详细输入见 [PPO_INPUTS.md](PPO_INPUTS.md)，方法见 [README.md](README.md)，DERL代码和算力比较见 [DERL_REPOSITORY_REVIEW.md](DERL_REPOSITORY_REVIEW.md)。最终数值见下方实验结果。

## DERL 对归因的帮助

DERL 的关键是“可靠内层学习 + 大规模异步形态评估”。每个新结构从随机控制器开始，不承担我们的 BC 接续问题；采用可学习探索、较长 rollout 和数百万步预算，操作任务主要是推物体，不能据其结果断言精细抓握也应直接收敛。

本项目最应复用的是公平适应度、合法形态生成、异步评估和足额内层学习。1152 CPU / 288 并行形态解释了其搜索速度；我们的单卡试跑适合定位机制，不足以复现其统计规模。修好内层之前扩大种群，只会更快累积有偏分数。

建议顺序：验证固定手接续的长期稳定性；单独核查异常变异与运行时轴限制；再比较较长rollout和渐进探索；最后恢复8个体搜索，对候选增加预算和独立seed。保持后代不做BC，但保留对优胜结构统一初始化训练的最终复核。

## Critic 校准与更新机制实测

校准组以当前随机策略采集32环境×1500步，按环境划分24训练、8验证。500次Critic拟合后，验证RMSE从7.111降至0.332，平均偏差从-6.956降至0.006，目标回报均值6.988（已乘0.01奖励缩放）。Actor最大参数变化为0。验证集用于早停/模型选择，因此这些数值衡量校准拟合，不是独立任务泛化成绩。

PPO更新后监控曾发现候选KL约0.197，已回滚。固定小标准差下，KL按均值差除以标准差的平方计算，因此很小的绝对动作变化也可能对应较大分布变化；仅降低学习率无法替代实际更新测量。最终接受/拒绝数量、Actor参数变化和完整回合结果见最终证据。接受了更新也不等于学到了更好的行为，需要同时检查性能与探索能力。

## 最终实验结果：组合方案未通过

| 组别 | 更新前成功 | 更新后成功 | 配对丢失/新增成功 | 总墙钟时间 |
|---|---:|---:|---:|---:|
| 不更新重复评估 | 31/32 | 31/32 | 0 / 0 | 5.37分钟 |
| 常规接续 | 31/32 | 29/32 | 2 / 0 | 12.54分钟 |
| 完整回报校准＋独立Critic LR＋KL回滚 | 31/32 | 15/32 | 16 / 0 | 11.71分钟 |

三组总计约29.6分钟，包含初始化、评估、校准和训练。两种训练各有65,536次Actor阶段交互，后代BC次数均为0。两个机制单元测试通过：零扩展保留初始输出且新列可学习；大更新可回滚、小更新可接受。

校准组接受636次、拒绝4次Actor更新；最大接受KL为0.00458，最大候选KL为0.19723，最终Actor LR为6.25e-9。Actor确实变化：参数变化L2范数0.000507，新增观测权重L2范数0.0000923。常规组Actor参数变化L2为0.002301。**参数变化更小的一组反而失败更多，因此“小变化就能保住BC”在当前系统上不成立。** 参数范数也不能直接当作相同状态下的动作变化或实际物理位移。

校准组最终无掉落（掉落定义为物体z<0.15m），最大单指合力3.34N，最大关节越限8.34e-7rad，最大物体速度0.355m/s，未触发已设严重异常。15例最终持续持握，另外17例最终保持时间为0。20秒采样时失败组的物体升高约为0或负值，而成功组约3cm，说明差异不只是最后一帧保持计时清零；存在未完成有效抬升/抓握的行为分化。现有稀疏遥测不能精确定位首次失效时刻，不能据此声称已排除所有接触建模问题。

### 能够确认

1. 新增观测没有破坏初始成功率；不更新的配对重复评估完全一致。
2. 校准确实拟合了当前策略完整回报，但这不保证后续优势估计方向正确。
3. 当前局部KL回滚并不保证25秒闭环任务性能。更新累计、访问状态改变、临界接触处敏感性均可能导致失效。
4. 本次基准失败没有伴随之前某些变异的数百牛过力或大幅越限；不能将两类失败混为一谈。

### 不能确认

不能把15/32单独归因于“Critic LR过大”或“新观测有害”。校准、Critic独立学习率、KL控制同时变化，且两组随机动作流不相同；验证只有一个环境扰动seed。也不能声称常规组长期安全：本次Actor训练仅128epoch，上轮更长训练已出现明显崩塌。

### 接下来应怎样设计接续

**不将本次校准组用于正式进化；保留已验证BC种子及所有实验checkpoint。** 下一步需要一个真正以任务效果检验更新的接续闭环：

1. 在固定代表性状态集比较更新前后动作、价值与优势，包含接触建立、抬升、受扰恢复；检查Critic误差是否集中在决定成功的分支。
2. 单项对照较长rollout、Critic学习率/预热方式；先把“能给出正确改进方向”与“每次更新幅度小”分开验证。
3. 每个短训练段后做同一组完整回合评估，退化时回退到最近最佳策略，并恢复对应优化器/价值状态。比较基准随新策略改善而移动，不永久绑定第0代BC。
4. 先看单形态的多seed长期趋势，再逐步放大探索。后代初始成功率低时仍允许学习，不把父代成功率强加为形态准入门槛。
5. 若需跨较大形态变化复用策略，增加显式基因/物体信息或形态归一化表达，另做接口版本迁移；当前108维不含这些信息。

这是一条基于本次反例修订的建议，不是已经验证成功的新算法。当前未恢复正式形态训练。
