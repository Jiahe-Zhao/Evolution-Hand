# 观测补足与 BC→PPO 接续验证（2026-10-25）

## 目的与范围

固定此前已校准机械手、自由工具、物理参数和成功判据；不修改手结构，不增加 BC。这里只做基准手的小规模接续验证，不据此宣布形态搜索或四任务收敛。

## 观测：67 维扩展为 108 维

原 67 维顺序和缩放保持不变，追加：

- 连续稳定保持时间 / 3 秒（1 维，上限 1）；
- 五指三轴带符号接触力 / 2 N（15 维）；
- 21 个手指关节速度 / 0.45 rad/s（21 维）；
- 手根三轴线速度 / 0.1 m/s（3 维）；
- 物体与支撑面的接触力标量 / 2 N（1 维）。

所有输入仍裁剪在 [-5,5]。这补充了与奖励和控制有关的信息，不宣称完全观测接触求解器内部状态。为隔离接续机制，未同时修改原来的世界 X 方向接触奖励与任务成功判据。

导入旧 BC 时，仅扩展 actor 第一层：原 67 列权重复制，新增 41 列置零。数学上初始动作函数保持不变；实际浮点计算和接触重置仍可能有差异，因此设置不更新重复评估对照。新输入列随后允许 PPO 正常学习。

## 三组对照

统一 32 环境、1500 步（25 秒）完整回合、同一 seed、同一 BC29；两种训练均有 128 个 actor PPO epoch（共 65,536 次 actor 阶段交互）。使用原有 16 步 rollout，每批优化 5 次。

1. control：新观测导入后做两次不更新完整评估。
2. standard：新观测、128 epoch 常规 Critic 预热，再 128 epoch actor PPO；保留原自适应学习率。
3. calibrated：新观测、完整随机策略回合的 Monte Carlo 回报拟合 Critic，再做 128 epoch actor PPO；Actor 初始学习率固定 1e-7，Critic 单独保持 3e-4，更新后检查 KL，必要时拒绝 actor 更新并降低其学习率。

两种训练共同关闭 value normalization，使用真实的已缩放奖励单位（reward_scale=0.01）。因此 standard 是本次共同配置下的对照，不能当作上轮 67 维实验的逐参数复现；calibrated 同时改变价值校准和更新控制，是组合方案验证，不能独立归因每个组件。

旧预热流程在解冻 Actor 后，Critic 也降到 Actor 的低学习率；本组用独立 optimizer 参数组避免这种限制。仍沿用整体梯度裁剪，未声称已排除所有梯度尺度耦合。

## Critic 校准

收集当前继承策略的随机动作完整回合，只使用未来能追溯到真实终止的样本；对未终止的尾段不伪造零终值。按环境拆分训练和验证集，避免同一条轨迹的相邻时刻同时进入两组。

回报包含现有终止奖励、惩罚和势函数塑形，gamma=0.9995。只训练 critic，actor 参数变化必须为零。最多 2000 次拟合更新；验证 RMSE < 0.5、平均偏差绝对值 < 0.2 后才允许接续 PPO。失败时明确停在校准阶段，不偷偷延长 BC。

阈值是本次诊断标准，不是收敛定理。验证集参与早停和最优拟合参数选择，不是独立的最终测试集。

## 更新控制

每次 PPO 优化后，在当前采样 batch 上计算新策略与 rollout 策略的平均 KL。超过 0.01 时，恢复该次 actor 参数、清除其动量并将后续学习率减半（下限 1e-9）；critic 更新保留。

约束参照是本轮采样策略，不是第零代 BC。actor 没有永久冻结，也没有 BC 损失。该局部 KL 检查不保证长期任务性能；必须核对接受/拒绝更新数，避免把“完全不学习”误报为稳定接续。

## 比较限制补充

环境初始扰动集合相同，但校准组额外随机采样并重设采样随机种子，因此两组 PPO 的随机动作流不配对。校准组另有 48,000 次完整回合采样和 Critic 监督拟合计算；仅 Actor 阶段交互预算相同，不是总算力完全相同。128 Actor epoch 仅覆盖每环境 2048 步，约 1.37 个25秒回合；最终另做完整回合评估，不能代替更长训练曲线。
