# 可学习探索与局部坐标适配（2026-10-25）

## 范围

独立验证版本；不修改 URDF、质量/惯量、碰撞几何或控制速率，不恢复正式形态搜索，不增加后代 BC。上一版 Monte Carlo Critic 校准组合失败，因此本次不使用该拟合阶段，也不宣称这套新组合已解决收敛。

## 探索

rl_games 的 fixed_sigma=true 表示状态无关标准差，不等于参数不可训练。本版将 log_std 的 requires_grad 打开，每个动作维度分别学习。初始手指std=0.0005、腕std=0.0001；投影上下限为初始值的0.25～4倍，即手指[0.000125,0.002]、腕[0.000025,0.0004]。这是保守验证范围，尚不保证足以适应大形态变化。

初始 sigma 学习率1e-4，entropy_coef=0.001；Actor初始1e-7，Critic3e-4。先128epoch只预热Critic，Actor和sigma必须保持不变，随后128epoch联合更新。std是全局每维参数，不随接触阶段改变；不声称有状态自适应探索。

采用完整对角高斯 KL(old||new)，包含均值与方差项；超过0.01则同时恢复Actor、sigma和二者优化器状态，降低其学习率；Critic更新保留。旧的固定方差KL检查不再使用。该阈值只约束本批数据，不能保证长期性能；上一版失败已经表明这一限制。

## 观测：108扩展133

前108维维持原编码，新增加25维：

- 108–110：物体相对手根的位置，在手根坐标系表达，/0.05m。
- 111–113：物体相对手根的速度，在手根坐标系表达，/0.1m/s；减去根部线速度与旋转坐标系的 omega×r 项。
- 114–117：物体相对手根的姿态四元数 wxyz，统一取w非负的表示。
- 118–132：五指接触合力在物体坐标系中的XYZ分量，/2N。

仍裁剪到[-5,5]。Actor第一层从67或108维扩展到133时，新列置零；在相同旧观测下初始动作均值不变。Critic重新初始化。旧坐标观测没有删除，因此整个策略尚不具备严格旋转不变性；本次是可兼容的增量适配，而非重新训练一个完全局部坐标策略。

## 奖励与判据

当前物体局部X轴对应已有抓握的两侧表面法向。将原先世界Fx的接触强度、两侧相向力和接触判据统一改为物体局部Fx；均使用真实接触合力，不增加虚拟吸附或约束。相向力判定仍为拇指与四指合力的局部X分量乘积小于0。

物体抬升继续相对重力方向；直立、脱离支撑、连续3秒持握、速度和过力等阈值保持原值。控制目标、末端奖励与势函数形式保持不变；这里不把“物体旋转不影响接触表达”误写为“任意姿态均算成功”。以后抓握不同物体或不同面，应显式配置抓握轴，不能固定把所有任务的X轴都视为法向。

## 验证与限制

单元测试覆盖旋转坐标转换、含方差的KL、旧BC扩维兼容和sigma回滚。运行32环境、同一扰动集合、完整25秒评估，含18秒外力脉冲。Actor阶段65,536次交互；rollout仍16。本次同时改变观测、接触表达和探索机制，只验证可运行性及初步趋势，不作单因素因果结论。最终评估使用均值动作，训练使用随机动作；不宣称随机策略已通过独立泛化评估。

新增特征仍来自仿真真值。形态基因、接触点/局部滑移没有输入。未把DERL的初始std=1直接套用到精细接触控制。

## checkpoint 与复用

导出的 checkpoint 包含已学习的 log_std。同版本 checkpoint 使用 eval 模式时恢复该参数，避免评估时错误退回初始噪声。新后代的 PPO 仍按既有弱遗传规则继承 Actor 均值网络，重新设置初始探索尺度；本版没有把学习到的方差继续跨代继承，避免探索上界逐代倍增。

本次仿真使用的精确脚本和辅助模块保留于 evidence 的 snapshot 文件。运行后补充了导出方差恢复测试及 eval 入口；这些补充不改变本次 PPO 训练路径。
