# 运动能力与碰撞模型修正

日期：2026-10-21。模型版本：`motion_contact_v3`。

## 结论

已修正四指侧摆与屈伸共轴的问题；机械生成器、左右镜像及共享碰撞导入已接入正式代码。17 个不同形态通过静态验证；5 组全手物理运动测试和 2 组指腹接触测试通过。原训练保持暂停。

本次结果证明生成与运动/接触基础可用，不代表四任务成功，也不代表自由工具击打已验证。

## 实现内容

1. **运动轴**：四指 MCP 侧摆采用局部 Y，原屈伸轴 X、正方向、关节名称和原限位保留。归档骨 URDF 经编译时，也会修正已知的重复侧摆轴。左右手按反射后的旋转轴规则生成。
2. **轴承方向**：指节两端轴承方向由实际关节轴及相邻关节坐标变换计算，避免结构模型固定绕 X 而运动轴已经改变。侧摆关节添加对应轴向的轴件代理。
3. **指腹接触**：末端采用真实显示与碰撞一致的圆角聚合物包覆层，包覆同段轴承。不是单独关闭仍裸露的轴承碰撞。包覆余量按指粗自适应，在 0.3–0.8 mm 之间。内部金属质量保留，并扣除被金属占据的聚合物质量。
4. **指节形状**：从骨结构源网格提取弯曲中心线，使用四段连续凸体表示；相邻关节的完整三维平移决定连接端点。修复旧编译器将曲线重新拉直、仅取连接 Z 分量的问题。
5. **质量惯量**：变异后重新计算质量、重心与惯量；检查正定及主惯量三角关系。仍属于材料密度与零件几何的工程代理，未含实测电机、传动和电子器件标定。
6. **统一碰撞配置**：模型版本在 `hand_collision.py` 中选择共享材料与碰撞设置，训练/测试共用。指腹摩擦 0.8、金属 0.2、恢复系数 0、接触提前量 0.3 mm、静止间距 0；指腹接触刚度 3000 N/m、阻尼 10 Ns/m，均沿用前一基准。没有通过提升摩擦实现测试通过。
7. **显式凸碰撞**：各接触网格显式设置 convexHull，避免依赖动态三角网格的隐式回退。圆角网格保持较低顶点数。自碰撞继续开启，沿用基于连接拓扑的关节接口过滤。
8. **缓存失效**：进化生成管线指纹包含新的模型和材料模块，防止原路径复用旧模型。保留原机械家族名称前缀用于既有执行器参数识别，实际版本记录在 mapping 和 gate 报告内。

## 变异兼容性

| 变异类型 | 本次检查 |
|---|---|
| 单段指长 | 正负变化；端点、网格和惯量随动 |
| 指粗 | 正负变化；轴承、指腹包覆及质量随动 |
| 拇指长度 | 正负变化 |
| 掌部曲率 | 正负变化；保留对应根部姿态 |
| 关节平移 | 三维偏移；保留非 Z 分量 |
| 关节姿态 | 在允许的末端关节上正负变异 |
| 增加指节 | 拇指及食指；21 自由度变为 22 |
| 删除指节 | 食指及中指；对应本次操作为 19 自由度 |

共 17 个用例，生成 17 个不同 URDF，左右手静态几何与镜像运动检查通过。详细记录见 `final_delivery/matrix.json`。

**已有变异限制保留**：`tools.change_joint_origin_rpy` 对手指前三段返回原结构，保护屈伸坐标系与正方向。本次没有解除这个限制。初版测试误选受保护根关节，随后改为实际允许变异的末端，并增加“非基准用例必须改变基因”的检查。任意极端参数组合仍可能物理无效，本次没有宣称全参数空间均通过。

## 物理测试

| 测试 | 结果 |
|---|---|
| 基准手大幅闭合与张开 | 通过；峰值速度 0.3703 rad/s，最大跟踪误差 0.06136 rad |
| 增加指节 | 通过；22 自由度正常导入和运动 |
| 删除指节 | 通过；19 自由度正常导入和运动 |
| 左手镜像 | 通过 |
| 时间步从 1/240 s 减半至 1/480 s | 通过；对应采样时刻的最大关节位置差 0.000385 rad，约 0.022° |
| 独立指腹压触 | 通过；约 2.02 N；首次报告接触来自 finger_pad |
| 独立双指腹悬空承重 | 通过；80 g 物体移除支撑后保持 3 s，最大位移约 0.00446 mm |

全手运动测试未出现有意义的关节越限（数值量级约 1e-16 rad）。运动命令采用五次插值，位置、速度、加速度连续；最大目标速度低于原 0.45 rad/s 的关节速度限制。该插值属于验证轨迹，不声称已替换所有 PPO 动作处理。

全手测试沿用生产导入的固定基座及手部重力关闭设置；指腹承重台物体受重力。承重台是将实际指腹安装在独立平移夹具上的隔离测试，不能替代整手主动抓握、挥动或 Strike 成功。接触材料尚未实机标定。这里的最大跟踪误差包含有限刚度驱动的动态滞后，不等于关节越限。
