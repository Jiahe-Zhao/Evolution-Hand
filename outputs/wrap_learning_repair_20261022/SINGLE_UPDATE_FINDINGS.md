# BC29 单次 PPO 更新定位

## 设置与结果

`single_update36`：同一组 64 个初始位姿，25 秒，包含外力扰动。冻结 BC29；128 轮只训练 Critic，随后恰好一次 Actor 优化器更新，跳过其余 4 次 minibatch 更新。没有修改手结构。

更新前 63/64，更新后 62/64；仅环境 63 从成功变为失败。BC 参数变化严格为 0。单步学习率 1e-7。在同一批完整评估状态上，直接新增腕部动作最大约 0.0000207 mm，手指约 7.24e-8 rad。这是极小的单次更新，不代表连续多轮累积后仍然极小。

## 能支持的结论

- RL 动作发生变化本身不是失败。单次 63/64 与 62/64 的差别不足以证明策略更新有系统性问题。
- 价值预热没有达到充分校准。初始状态的 Critic 预测从 0.016 提高到 0.168，而确定性 BC 轨迹的折扣回报均值约 4.651；20 秒时预测约 0.932，轨迹回报约 8.388。已按训练 reward_scale=0.01 和 gamma=0.9995 对齐单位。完整状态集 RMSE 从 7.085 降为 6.335，仍较大。
- 以上回报来自确定性策略，是价值校准线索，不是随机策略期望价值的无偏估计，不能直接证明每个 PPO advantage 的符号错误。
- 配对回合的初始可观测状态一致，但第一物理步后的物体位置已有最大 0.330 mm 差异。必须增加“完全不更新的重复重置”对照，才能区分接触数值/求解器历史与策略反馈影响；不能将后续最大轨迹偏差全部解释为微小动作被放大。

## 对后续进化的意义

应允许短期回报波动，保留最好策略供比较，但不要求每次 PPO 更新单调提高成功率。BC 可以提供初始化；永久锁定 BC 或永久限制为极小残差不适合作为最终形态探索算法。

当前有价值的后续检查是重置可重复性、足够完整回合上的价值校准和较长学习曲线。这个单次实验不宣称 PPO 已收敛，也不否定 PPO 的可用性。完整形态—策略联合优化建议见 `MORPHOLOGY_RL_DESIGN.md`。

原始逐步轨迹和更新 minibatch 保留远端，未放入 Git；`single_update_analysis.json`、`single_update.json`、`single_update_status.json` 和 `residual_contract.json` 保存主要证据。
