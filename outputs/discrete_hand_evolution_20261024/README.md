# 八基因三档与第零代 BC

后续已授权启动：[基准＋7 个后代试跑](PILOT_8.md)。启动记录不代表训练已经完成。

## 实现范围

这是独立、显式启用的进化入口。原 `main_evolution.py` 和暂停的训练进程没有修改或恢复。

- `genes.py`：8 个离散基因，编码为 `-1/0/1`，共 6561 种组合；不穷举。
- `build_candidate.py`：生成骨手、右机械手、左机械手，更新实体网格及质量/惯量，并做静态审计。
- `inheritance.py`：第零代 BC 权限、动作接口检查、只继承 actor。
- `worker.py`：已接入上述约束的自由工具抓握 PPO 训练入口，基于此前校准环境。
- `evolution.py`：生成后代、生成/执行训练命令、按同条件评估结果保留个体。
- `import_seed.py`：验证已完成的 BC 运行，把 BC29 导入第零代，不重复训练 BC。

骨手和双侧机械手的模型生成均已覆盖。训练适配器当前只覆盖已校准的右机械手自由工具抓握，不能据此宣称骨手或四任务训练全部接通。

## 基因定义

所有档位相对不可变的 `baseline_genotype.json` 计算。当前手为八项全部中档。

| 基因 | 低档 | 中档 | 高档 | 实际定义 |
|---|---:|---:|---:|---|
| 掌宽 | 0.9 倍 | 1 倍 | 1.1 倍 | 当前机械掌横向 Z 尺寸 80 mm；三档 72/80/88 mm，同时改变指根间距 |
| 四指展开 | −5° | 0° | +5° | 以中指为中心改变扇形开合，中指不动，食指与无名/小指方向相反 |
| 四指长度 | 0.9 倍 | 1 倍 | 1.1 倍 | 四指等比例变化，保留各指相对长度 |
| 近节比例 | −0.05 | 原比例 | +0.05 | 根部近节占该指总跨度的比例；其他段按比例补偿，总长保持 |
| 拇指长度 | 0.9 倍 | 1 倍 | 1.1 倍 | 所有拇指段共同缩放 |
| 拇指根横向位置 | −4 mm | 原位置 | +4 mm | 固定为基准掌宽的 5%，不与掌宽变异重复相乘 |
| 拇指对掌轴 | −5° | 原轴 | +5° | 在对掌关节局部坐标绕 Z 旋转轴方向，保留原正向定义 |
| 指腹宽度 | 0.9 倍 | 1 倍 | 1.1 倍 | 末端包覆指腹局部 X 宽度；轴承不变，重新计算惯量 |

长度采用相邻关节间跨度，末端采用末段长度，包含焊接指尖。机械手和骨手采用同一基因编码，但接触几何生成方式不同。骨手末端横向变宽不会反过来扩大机械手轴承。

指腹缩小必须仍包住轴承，至少留 0.1 mm 几何净余量；不满足时报告不可行，不静默裁剪。骨手的掌宽基因改变根部布局和生成的掌部；表中 80 mm 是机械掌底盘尺寸。

## 世代和遗传

1. 第零代建立全中档基准，并运行 BC。也可导入本场景已经验证的 BC29。
2. 第一轮搜索从该种子生成邻近形态；建议保留基准，再加 7 个不同后代，共 8 个。
3. 每次出生只改变一个基因的相邻档位。不能低档直接跳到高档，也不累乘尺寸。
4. 后代必须有兼容的父代 checkpoint。没有兼容父代时明确报错，禁止偷偷回退到 BC。
5. 后代完整继承 actor 的可匹配参数；critic、价值归一化统计、优化器动量和训练计数重新开始。探索标准差由子代配置重新设置。
6. 先训练 critic，再解冻 actor 做 PPO。没有永久冻结的 BC 主干、没有持续 BC 损失、没有随机打乱网络权重。

这里“弱遗传”指只继承动作策略这一部分训练状态，不是将权重乘 0.1 或随机重置部分神经元。后代 actor 完全可训练，因此允许适应新结构。

动作接口必须保持同一任务、观测含义、关节顺序、限位及网络形状。几何改变本身不被判为接口不兼容。未来新增/删除关节需要另一个适配器。

## 收敛和选择

本方法减少冷启动，不保证收敛。此前长一些的 PPO 仍出现成功率回退，不能用本次接通测试代替收敛证据。

默认保留原校准参数：256 环境、actor 学习率 1e-7、手指标准差 0.0005、腕部标准差 0.0001、gamma 0.9995、25 秒回合；物理参数不作为搜索基因。默认 512 轮约 2.10M 交互，含 128 轮 critic 预热。128 轮预热不是“价值已经收敛”的保证，正式试跑应检查完整回合回报和价值误差。

选择采用相同评估场景、随机种子、回合数和训练预算，不能混比训练分数。`select` 保留最优个体，并在保留数大于 1 时预留一个结构多样性名额。基准作为参照单独保留；不要因一次短期回退直接淘汰全部新结构。

建议下一步仍采用 8→4→2 的预算递增试跑；本入口已实现出生、单个训练作业和筛选，尚未实现无人值守的多阶段恢复调度。正式多阶段续训需要保留同一个体的优化器/critic 状态，不能把它误当成新一代再次执行 actor-only 初始化。

新结构的旧抓握初始化若发生穿透，要求重新规划初始姿态；这不是“结构任务分数为零”。脚本抓不起来也不自动拒绝结构。静态模型有效与任务能学会是两件需要分别验证的事。

最终优胜形态应使用多个训练种子复核。遗传策略下的胜出同时受结构和父代技能影响，不能直接证明其机械结构全局最优。

## 远端使用

目录：`/home/zjh/Evolution_PC/outputs/discrete_hand_evolution_20261024`。
Python：`/home/zjh/miniconda3/envs/evolution_isaaclab/bin/python`。
以下使用 `python` 表示该解释器。所有输出目录必须是新的。

```bash
python -m unittest -v test_discrete
python evolution.py offspring --parents seeds/g0/parent.json --count 7 --output births.json
python build_candidate.py --baseline baseline_genotype.json --code '[0,0,0,0,0,0,0,-1]' --output NEW_CANDIDATE
python evolution.py run --job example_job.json --output NEW_TRAINING
# 检查输出命令后，添加 --execute 执行。
python evolution.py select --results comparable_results.json --keep 4 --output survivors.json
```

`example_job.json` 指向本次已经生成的变体及种子。新结构应传入该结构重新验证过的初始化计划。训练入口还会在实际网格上复核初始碰撞及关节限位。

生成器依赖现有 `Isaaclab_other` 的校准编译器；每个候选记录其源码哈希。训练依赖此前 `wrap_learning_repair_20261022` 和 `contact_control_calibration_20261021` 的辅助模块及现有 IsaacLab 环境。大模型、网格和轨迹留在远端，Git 保存实现与验证摘要。
