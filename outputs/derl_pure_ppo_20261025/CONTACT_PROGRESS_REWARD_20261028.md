# Branch / Forage 奖励修订与验证

## 为什么改

势能差 `gamma*Phi(next)-Phi(now)` 本身是合理的塑形方法，不等于“错误奖励”。但此前 Branch / Forage 仅有势能差与最终成功奖励，并在终止时清零势能。完整失败回合的原始折扣回报等于 `-Phi(initial)`；同一初态下，不同失败路径没有不同的原始折扣任务目标。成功极少时，这不足以保证学到有效阶段动作。

这次明确改变任务目标，允许有效但未完成的尝试获得部分分数。并不声称保持原最优策略不变，也不把部分分数当成任务成功。

## Grasp 实际做法

`goal_worker.py` 每步奖励：

`靠近 + 接触平衡 + 5*目标抬升进度*抓持质量 + 3*目标内稳定保持 - 0.1*过大力惩罚 - 2*过快运动惩罚`

回合结束达到保持条件再加 10，物体掉落扣 10。抬升质量包含反向接触、力平衡、速度与直立程度；不能只把物体撞飞就获得同等奖励。目标高度为 25/40/55 mm。Grasp 使用持续稠密奖励，而不是当前原生任务的纯势能差。

Grasp 当前成绩不能单独证明其奖励是唯一成功原因；场景、初态、控制接口与任务时序也不同。本次不改 Grasp，也不把其奖励系数直接搬到其他任务。

## 新规则

令每个阶段进度 `p_i` 在 `[0,1]`，`b_i` 为本回合此前最高进度：

`r = sum_i w_i * max(p_i-b_i,0) + 10*真实成功 - 软代价`

随后 `b_i=max(b_i,p_i)`；reset 时用初态进度初始化。当前进度与历史最高进度均进入观测，避免隐含的奖励记忆不被策略看见。

- 同一阶段反复接触、松开、恢复到原水平，不重复奖励。
- 每回合部分进展奖励总上限 10；真实成功另加 10。
- 失败或超时不追回已获得的进展分。
- 不增加基于单帧力、速度或小幅越限的失败终止。
- 有上限不代表完全免疫奖励漏洞：仍须检查是否靠不合理接触刷出首次进展，以及策略是否停留在部分完成。

### Branch

| 进度 | 权重 |
|---|---:|
| 拇指接近树枝表面 | 0.5 |
| 两根长指接近树枝表面 | 0.5 |
| 拇指接触强度，达到1 N后饱和 | 0.5 |
| 两根长指接触强度，达到1 N后饱和 | 0.5 |
| 拇指与至少两长指同时接触 | 1 |
| 两侧反向合力 | 3 |
| 连续对掌保持进度 | 4 |

最终成功仍是当前原生对掌、力阈值、稳定性与15步保持判定。使用已验证的共同网格3位置、±2 mm扰动、现有非穿透reset和接触新鲜度防护。关节控制不变，没有BC或动作覆盖。

### Forage

| 进度 | 权重 |
|---|---:|
| 手指靠近叶片 | 1 |
| 真实触碰两片叶子，各一次 | 0.5+0.5 |
| 两片叶子朝目标边界外移开的进展 | 1+1 |
| 食物实际投影露出率 | 4 |
| 完成后稳定保持进度 | 2 |

移动进度采用叶中心相对目标的XY距离，按叶片投影半尺寸与目标半尺寸之和归一化，取较接近清除的轴。因此即使目标仍被完全覆盖，叶片朝边缘移动也有信号。移动分数要求该叶片有真实接触历史，并随速度平滑衰减。露出率仍用已有保守投影覆盖算法。

最终成功仍要求露出率≥98%、两片均接触过、速度<0.15 m/s、保持0.5 s。真实桌面、自由叶片、质量和摩擦均不变。

### 时间与物理代价

- `gamma: 0.99 -> 0.999`，同时应用于GAE与回报归一化。60 Hz下10秒奖励权重从约0.0024变为0.5486，40秒后约0.0906。
- 保留GAE lambda=0.95、rollout=128、64×64网络、学习率3e-4线性下降、可学习探索方差等参数。
- 软代价按秒计：时间0.01；超过40 N的接触力和Forage超过1 m/s的速度，使用有上限的二次成本，系数各0.05。阈值是本轮试验值，不是硬件安全标准。
- 奖励、gamma和观测扩展同时变化，本轮是组合验证，不能单独归因某一项。
- 新观测维度不同，随机初始化新策略，不直接读取旧检查点。

## 验证与当前结果

- 12项测试通过：奖励预算、重复接触不重复给分、覆盖前移动信号、终止保留部分奖励、成功奖励独立、GAE折扣，以及旧奖励兼容、折扣一致性和首回合评估。
- Branch：256环境，1,048,576步纯PPO；训练完成768回合，成功0。最终两次随机与一次均值动作均0/256。末次训练记录有拇指/长指独立接触进度，但同时接触、对掌、保持进度仍为0。不能宣称已经改善成功率。
- Forage旧顺序脚本：完整2399步，零成功；最高露出率4.35%，峰值力0.737 N、叶速0.0236 m/s。上层叶拨开后，剩余时间未完成下层；不是这次测试中的弹飞。
- Forage并行扫拨诊断：16条有限路径，零成功；最佳露出率47.83%，对应峰值力2.23 N、叶速0.138 m/s。证明有可控移动与部分露出，尚未证明完整任务可达。
- Forage新奖励PPO：256环境，完成2,097,152步，训练完成768回合、训练成功0。最终两个随机动作种子各0/256；均值动作 **4/256（1.56%）**。这是严格的≥98%露出、双叶接触历史、低速连续保持成功，未把部分露出算成功。
- Forage比Branch多一倍步数，是因为其回合40秒、Branch20秒，使每环境获得约相同的回合长度预算。训练吞吐约4026步/s；训练日志中的峰值力37.57 N、峰值叶速1.342 m/s，没有非有限状态中断；瞬态速度不等于成功时速度。
- Forage出现少量均值动作成功，说明有限策略能够完成新场景；单个训练种子、1.56%成功率及随机动作全零，不足以证明稳定收敛，也不能单独归因奖励修订。Branch尚无成功。

## 下一步建议

奖励接口与部分进展计分已修订并通过完整回合验证，但不宣称两任务已解决。Branch下一项应为控制/探索消融，检验手指协同与时间连续探索；Forage先复核少量成功轨迹及随机探索破坏因素，再决定扩大预算。保持最终成功判定，不把失败回合的进展分用作形态搜索的成功率。
