# Branch 局部位置搜索、重置接触保护与短 PPO

## 目标与范围

在不修改手结构的前提下，小范围平移树枝，找到拇指与长指实际对掌保持的位置，再加入扰动并运行短程纯 PPO。原始场景保留；本次训练通过独立 placement manifest 启用新分布。

手的 URDF、质量/惯量、关节轴、关节限位、碰撞几何未修改。场景仍为固定树枝、固定手根；因此成功表示对掌接触保持，不代表自由物体承重或抗外力能力。

## 搜索与选定位置

- 在树枝横截面两个方向分别搜索 ±30 mm，7×7 共 49 个位置；每位置 16 个初始关节构型，共 784 个优化起点。
- 使用实际 URDF 正运动学和实际关节控制限位。FK 与仿真位置误差约 6.74e-7 m。
- 几何候选只是搜索代理，不等同于无碰撞抓握。64 个候选通过正常关节动作进行物理验证。
- 部分候选初始穿透，产生极大接触力，已排除；未以这类候选启动训练。
- 选定 candidate 57：相对原始重置位置，世界坐标平移 `(0, -30, -30) mm`；原有重置逻辑仍保留。
- 训练及测试均增加每轴独立均匀 `[-2, +2] mm` 平移扰动。保留原有关节初始噪声。
- manifest 保存关节目标、关节名称与基准 URDF SHA-256。当前仅验证这只基准手；换形态不能静默复用此证书，需要重新验证位置分布。

`branch_local_guarded_20261028`，32 个并行环境、两个随机种子：

|---|---:|---:|
| 原生对掌成功 | 32/32 | 32/32 |
| 连续对掌 ≥3 秒 | 32/32 | 32/32 |
| 初始假成功 | 0/32 | 0/32 |
| 连续保持步数 | 554–589 | 554–589 |
| 主动张开后接触清除 | 32/32 | 32/32 |
| 最后释放阶段峰值接触力 | 0 N | 0 N |

控制频率 60 Hz，保持约 9.23–9.82 秒。脚本先保持初始姿态 120 步，再在 360 步内逐渐闭合；首次达到原生成功条件后停止进一步闭合，1000 步开始张开。验证期间仅延长成功后的观测，不提前终止，以测持续保持。PPO 不使用该脚本、目标关节轨迹或 BC；训练仍按原生 15 步对掌保持判定成功。

所有重置使用实际导入碰撞几何做 FCL 检查，树枝外扩 0.5 mm 后仍需无交叉；此检查不是完整物理接触模型的证明。

接触峰值仍达到约 133.9 N（跨 32 个环境的最大指体合力）。说明抓得到，但尚不能视为已完成低力、柔顺抓握校准；后续应关注力分布与动作平滑性。

## 暴露的跨回合接触问题

在抓紧状态直接重置时，关节位置已恢复张开，PhysX 原生接触传感器及自建全手接触视图仍可能持续报告上一回合的力。重新运动后报告恢复更新。该现象可造成第二回合开局假成功。

已做对照：关闭关节休眠、显式唤醒、清理仿真力缓冲、清零 Python 查询输出，均未消除问题，相关实验保留。不能据此声称已修复 PhysX 内部实现，亦不能将其简单归因为休眠。

当前采用保守的传感器有效性保护：

1. 先以 FCL 验证实际初始姿态几何无碰撞。
2. 每次重置后，旧接触报告暂不进入观测与奖励。
3. 接触视图必须先报告一次全手对树枝的无接触帧（所有体合力 <0.05 N），才恢复计分。
4. 全手触觉和原生触觉观测同时保护，防止奖励被修好但策略仍看到旧力。

额外用 4 环境、两回合各 700 步，直接从抓紧状态重置。第二回合原始后端仍报告约 11.05 N 的旧力；有效性保护阻止假成功，直到第 280 步得到新鲜无接触读数。之后 4/4 再次形成真实对掌，并连续保持 245–251 步。这是保护机制回归验证；700 步试验未执行第 1000 步后的释放动作，不将其中默认零值当作释放验证。

限制：这是针对“几何无接触开局”的恢复机制；不适用于默认从接触/预抓握姿态开始的任务。当前仅由本次 Branch placement 配置启用，不全局修改其他任务。

## 短 PPO 配置

独立输出 `branch_local_ppo_v3_20261028/train`：

- 256 环境，524,288 transitions，16 次 rollout；每个 rollout 128 控制步。
- 从随机策略开始；BC 更新 0，无父策略加载。
- 网络、可学习探索方差、PPO 超参数保持现有 DERL 风格配置：64×64 tanh；初始学习率 3e-4 线性下降；gamma 0.99；GAE 0.95；clip 0.2；4 epochs；minibatch 512；熵系数 0.01。
- 原生对掌成功条件及目标条件观测保留；奖励不另加脚本轨迹模仿。
- 训练前完整回合评估；训练后两个动作随机种子以及均值动作完整回合评估。评估不更新归一化统计。
- 修正评估种子顺序：环境 reset 会重新设置 Torch 随机种子，因此动作随机种子必须在 reset 之后设置，才能保证多个动作种子确实产生不同轨迹。

## 短 PPO 结果

| 评估 | 成功 | 成功率 |
|---|---:|---:|
| 训练前，随机动作种子 1062803 | 0/256 | 0% |
| 训练后，随机动作种子 1062803 | 5/256 | 1.95% |
| 训练后，随机动作种子 1062804 | 3/256 | 1.17% |
| 训练后，均值动作 | 9/256 | 3.52% |

训练后两组随机动作共 8/512，即 1.56%。均值动作 9/256（3.52%），出现成功但仍远未稳定收敛。所有评估均完成完整回合，未达到步数上限的悬空回合为 0。这是同一个训练种子的两个评估动作种子，不是两次独立训练。第一组成功出现在第 752–1168 步，排除了重置后立即虚假成功的情况。

16 次 rollout 全部完成，每次 256 个 minibatch 更新，共 4096 个优化器更新。训练阶段完成 256 个回合，原生成功 0 次；末段 `held_fraction` 为 0.00516，只表示拇指与至少两长指同时达到接触阈值，不保证对掌方向及保持时间。探索标准差约 0.983–1.009，仍接近初始 1.0。评估已有少量真实成功，不能宣称稳定收敛，也不能用短程零训练成功推断任务不可能。

截至训练结束（含训练前评估）的累计单体目标接触峰值约 2120 N，最大关节越限约 1.19e-7 rad。控制配置仍限制关节力矩为 0.3/0.5 Nm、速度为 0.45 rad/s，PD 刚度 6、阻尼 1。大接触峰值的持续时长及分布尚未专门复核；不能仅据一个峰值断言失稳，也不能声称力学已经充分校准。

训练迭代含中间重置约 152 秒，平均约 3441 transitions/s；无大批量重置的前段约 6000 transitions/s。本次包含初始化、训练前评估和三组训练后评估的总耗时约 1205 秒（20.1 分钟）。完整实验更慢，主要因为每次重置按环境重复读取碰撞网格、重建凸包，且评估包含多次全量重置。下一轮优先缓存不变的局部碰撞几何，只更新刚体变换；应先验证缓存与现有检查等价，再替换，而非通过删掉几何检查提速。

结论：局部平移使当前手具备经过物理验证的对掌可达性，纯 PPO 也出现少量成功。保留该位置作为后续课程起点较合理；尚不宜直接扩大到多形态长训。后续先处理重置开销、检查异常接触力，再用更长训练预算和更多独立训练种子验证收敛。
