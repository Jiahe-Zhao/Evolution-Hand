# Branch：基准机械手 / Shadow 对照（2026-10-28）

## 目的与边界

区分任务摆放、接触仿真、控制接口和 PPO 学习困难。使用 Isaac Lab 安装版原生 Shadow USD；这不是 Shadow 实机性能测试，也不是复现官方任务的收敛成绩。

- 原手 URDF 与 Shadow USD 均不修改。Shadow 两个腕部关节在运行时锁零，匹配我们手的固定腕部任务。
- Branch 是固定圆柱（半径 9 mm、长 180 mm）。成功表示拇指和至少两根长指形成相反方向接触，并持续 15 控制步；不表示完成承重或树枝移动。
- 脚本只验证可达性，不作为 BC，不接管 PPO 动作。
- 旧 Branch 的 3.52% 不直接纳入这次对比：本次统一了接触材料与求解器，双方都重新训练。

## 公平性约定

| 项目 | 共同设置 |
|---|---|
| 物理时间步 / 控制频率 | 1/120 s / 60 Hz |
| 完整回合 | 20 s，最多 1200 控制步 |
| 求解器 | TGS，位置迭代 8，速度迭代 0 |
| 接触材料 | 刚性接触，静/动摩擦 0.8，恢复系数 0，接触偏移 0.3 mm |
| 接触观测 | 全部运行时刚体，对 Branch 的滤波合力、接触持续时间、力变化；不是压力阵列 |
| 判定 | 拇指 ≥1 N，至少两长指各 ≥1 N；两侧合力点积为负；保持 15 步 |
| 控制 | 关节位置目标，目标变化率上限 0.45 rad/s |
| PPO | 独立随机初始化，无 BC / 父策略；64×64 actor/critic；可学习探索方差 |
| 初步预算 | 每手 256 环境，3 个种子，各 1,048,576 环境步 |
| 评估 | 每策略 2 个动作随机种子 + 均值动作；完整回合；相同场景随机种子 |

保留各手原生/既有 PD、力矩、腱耦合和硬件速度上限。相同控制目标变化率不等于强制相同实际关节速度。Shadow 18 个指部主动自由度、4 个被动指节；我们手 21 个主动自由度。由于自由度和刚体数不同，观测长度、动作长度、网络参数量并不完全相同，另存 comparison_model.json。

初始关节噪声为各关节范围的 ±2%，树枝在解剖坐标系内 ±2 mm。独立场景 RNG 保证树枝扰动提案不受手的自由度数量影响；因各手几何可行域不同，接受后的初态不保证逐回合完全一致。仅在 reset 时排除初始穿透：最多重采样初始关节和树枝扰动 32 次并记录次数；不限制回合内探索动作。

## 位置搜索与基础验证

- 解剖原点：四长指近端关节中心平均值；x 为小指指向食指，y 为掌部指向指根组，z=x×y。
- 两手均用 49 个树枝位置 ×16 次初始化、400 步几何优化，选 64 个候选进行真实物理回放。
- 搜索的 Shadow 被动指节使用零腱伸长近似 `J0=clip(J1×0.00805/0.00705)`；最终结果以原生物理腱耦合回放为准。
- FK 与导入后刚体位置误差：我们手约 6.7e-8 m，Shadow 约 2.7e-7 m。
- 缓存碰撞几何与原逐次构造方法在 5 个探测位置一致。另检查非零 reset 姿态，Shadow FK/实际位置最大误差约 2.8e-7 m。
- 统一求解器后，≥3 s 保持候选：我们手 8/64，Shadow 6/64。分母包含初始摆放不合法候选，不能解释为 RL 成功率。
- 双方共同可行位置：搜索网格 3，解剖坐标偏移 `(23,-35,32) mm`。这是有限搜索发现的共同可行位置，不代表各自最优位置。
- Shadow 官方转方块环境关闭随机化后，1200 步随机动作均有限；这只是安装/资产运行检查。

## 接入时发现的问题

1. **仿真配置不能机械照搬。** 初版统一 64/16 求解器并向 Shadow 强加 0.45 rad/s 物理速度上限，出现极端力和非有限关节状态。只降低速度迭代、或只移除强加的物理速度上限，都未让整批检查通过。采用 Shadow 原生 8/0 求解器及原生速度限制组合后，64 候选完整通过，峰值约 31.74 N。尚不能把原因归结为某一个参数；当前证据支持“接入配置组合不兼容”。我们手也用同一 8/0 重新检查，整批峰值约 45.41 N。
2. **无效候选不能继续闭合。** 初始穿透候选现在保持开手并明确计失败，避免无效动作拖垮整批物理测试。
3. **reset 后接触报告可能滞留。** 保留已有修复：几何确认开手初态无接触后，必须看到一个新的全手无接触帧，才允许接触进入观测与奖励。
4. **随机初态偶尔穿透。** Shadow 扰动复核出现过初始拇指与树枝重叠；FK 验证表明并非位姿缓存错误。通过有记录的初态重采样处理，不把这种 reset 错误算成策略失败。

## 扰动与 PPO 结果

共同位置、32 环境×2 个场景种子，完整 20 s 脚本回合：

| 指标 | 我们手 | Shadow |
|---|---:|---:|
| 达到 15 步对掌判定 | 64/64 | 50/64 |
| 连续保持 ≥3 s | 61/64 | 43/64 |
| 释放后接触力 <1 N | 64/64 | 55/64 |
| 释放末期仍有几何接触/0.5 mm 内接近 | 0/64 | 9/64 |
| 全程峰值 Branch 接触力 | 9.15 N | 18.32 N |
| reset 重采样（含超时后的额外 reset） | 0/128 | 4/128 |

Shadow 的 9 次未释放与几何检查一致，不能一概归因于接触报告残留。当前任务只要求抓持，释放问题作为控制质量差异另列。

两手都具备完成该位置抓持的物理能力；当前结果不支持“我们手的结构必然导致 Branch 无法完成”。但有限脚本的成功率也不能证明全动作空间仿真稳定。

### 纯 PPO：六次均已完成

种子 2028、2029、2030；同种子两手交替顺序运行；每次 1,048,576 步，单卡顺序执行。六次训练及完整回合评估总耗时 **673 s（11.2 分钟）**，不含前期接入与物理排查。

| 训练种子 | 我们手随机动作（2×256） | Shadow 随机动作（2×256） | 我们手均值动作（256） | Shadow 均值动作（256） |
|---|---:|---:|---:|---:|
| 2028 | 0/512 | 2/512 | 0/256 | 29/256 |
| 2029 | 0/512 | 0/512 | 0/256 | 3/256 |
| 2030 | 0/512 | 0/512 | 0/256 | 0/256 |
| 汇总 | **0/1536** | **2/1536（0.13%）** | **0/768** | **32/768（4.17%）** |

这些合并分母用于描述结果，不把共享初态的重复评估当成完全独立统计样本。三个训练种子仍是很小的样本量。

- 训练期间完成回合：每种子各 768。我们手三次训练成功数全为 0；Shadow 为 5、0、0。
- 我们手训练中 `held_fraction` 始终为 0，即未探索到“拇指+至少两长指同时达到力阈值”。Shadow 三个种子的最大 rollout 比例分别为 7.24%、1.39%、0.21%；这项不要求反向合力，不能替代真正成功率。
- 学习后的高斯探索标准差仍约 0.94–1.03。Shadow 均值动作明显好于随机动作，提示持续随机探索会破坏已经较接近成功的动作；不是降低方差就一定解决的因果证明。
- 训练吞吐：我们手约 1.85–1.88 万环境步/s，Shadow 约 2.08–2.15 万环境步/s。相同步数预算的实际耗时不同。
- 模型：我们手输入 388 / 输出 21 / 参数 59,563；Shadow 输入 420 / 输出 18 / 参数 63,461。两者都有相同语义种类的状态与全手合力观测，但通道数不同。
- 六次均无 BC、无父策略加载；全部正常完成，无非有限状态导致的中断。
- PPO 期间记录的峰值力：我们手最高约 32.25 N，Shadow 最高约 92.55 N；主动关节最大限位偏差分别约 0.0101 rad、0.0717 rad。记录覆盖初次评估和训练至末次训练日志，不宣称覆盖其后所有最终评估。

### 当前归因与建议

1. **物理不可达并非主要已证实障碍。** 两手脚本都能在共同位置完成抓持；我们手脚本还更稳。不能把 PPO 的 0 分直接解释为我们的结构抓不了。
2. **探索到有效接触组合，是我们手当前更明显的卡点。** 三个种子都未探索到同时三指接触。Shadow 的自由度、耦合、关节范围和驱动不同，更容易偶尔形成组合；本次不能进一步拆分是哪一个因素造成。
3. **当前 PPO 配置在 Shadow 上也不稳。** 最好种子均值动作 11.33%，其他为 1.17%、0%；随机动作几乎全失败。换成熟手模型没有自动解决学习问题。
4. **仿真配置组合确实曾造成问题，但不是当前全部 0 分的充分解释。** 修改后的六次 PPO 都完整结束；仍需要区分数值稳定与物理真实性。
5. **暂不扩大形态种群。** 下一步建议在相同两手对照下，先做动作/探索消融：保留原始逐关节控制作基线，对比低维手指协同控制或有时间连续性的探索；再单独测试更长训练预算。避免同时改结构、奖励、控制和算力而失去归因。
6. 105 万步仅提供每环境约 3.4 个回合长度、总共 32 次 PPO rollout 更新，不能据此宣称长训练必然失败；但当前我们手零有效组合，单纯延长训练的收益仍不确定。
