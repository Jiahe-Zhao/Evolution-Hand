# DERL 对标纯 PPO：基准手＋两个小变异

日期：2026-10-25。参考仓库固定于 `agrimgupta92/derl@91e077e355b27bb74fa920c708d606ff9f4d611e`。

## 验证目标和范围

检验随机初始化 PPO 能否在当前自由工具抓握场景学会完整任务，以及小幅形态变异后能否重复学习。没有加载 BC、父代策略或示范轨迹；没有 Actor 预热冻结、BC 损失或专家动作。每个形态/seed独立创建随机 Actor、Critic、Adam 和归一化统计。

场景仍从此前经过碰撞检查的预抓取姿态开始。这是有任务先验的初始化，不是从任意远距离位置开始，也不等于没有人为设计。不同形态使用已有静态初始化计划，计划中的关节位置只用于物理 reset，不作为动作标签或策略监督。

候选复用已授权8基因3档模型：

1. 基准手，全0档。
2. thumb_lateral=+1：拇指横向偏移增加基准掌宽的5%。
3. thumb_length=+1：拇指总长度增加10%。

其他基因不变。没有修改结构生成规则、关节限位或碰撞屏蔽。该子集不能证明所有8基因组合都可用；已知thumb_axis运行时限制仍未解决。

## 任务适配：避免低gamma配长时稀疏奖励

25秒末端奖励在gamma=0.99下无法有效指导早期随机动作。因此采用逐步的密集任务奖励：

`reach + balance + 5×held_lift_quality + 3×held - 0.1×overforce - 2×overspeed + 10×terminal_success - 10×fall`。

- reach：5个指腹参考点到物体盒表面的距离经exp(-distance/0.02m)变换后平均。
- balance与相向力：使用物体局部X轴，沿用当前抓握面的定义。
- held_lift_quality：抬升仅在存在有效两侧相向接触时得分，并考虑物体直立和速度。
- held：沿用抬升>15mm、脱离支撑、两侧接触、直立和低速度条件。
- 终点成功仍要求完整25秒回合末端连续稳定保持至少3秒；失稳允许恢复。
- 过力与过速仍为软代价，不作为探索期自动终止条件。

奖励是本任务适配，不能称为DERL原奖励。它存在靠近奖励停滞等潜在局部最优，需要以完整成功率检查，不能用训练回报替代成功。

控制仍为21关节绝对目标角＋3腕部位移目标，动作裁剪[-1,1]，手指/腕部目标速率维持0.25rad/s、0.02m/s。物理240Hz、控制60Hz；未把DERL的力矩执行器模型直接套用。

## 观测与终止处理

沿用133维物体局部观测适配，增加15维指腹参考点在物体坐标系中的位置，除以0.05m，共148维。现有物理编码裁剪仍保留，再做统计归一化；无图像、形态基因或未来专家动作。各形态独立训练，因此本轮不要求形态条件共享网络。

25秒结束在本任务中有明确的成功结算，是有限时域终止；GAE不跨过该终点bootstrap。DERL对普通TimeLimit截断另有处理，不能在本任务直接照搬以消掉终点奖励。真实rollout边界且未终止时正常bootstrap。

## 预算、评估与运行

先对三种形态做2个rollout的短流程检查。smoke评估仅32步，不用于判断任务成功。

完整运行按seed轮询三种形态：2027、2028、2029，总9次，约4483万次训练交互。每次在训练前、约250万步、末尾做256环境的完整25秒均值动作评估。评估使用独立的对象扰动集合（eval_seed=92027），不更新归一化统计；该集合同时用于选择best，属于验证集，不宣称独立最终测试集。训练期间随机策略的完整回合结果也单独记录。

评估会重置训练环境，丢弃尚未完成的回合；训练成功计数只计完整回合。5M是本轮固定比较预算，不是保证收敛的充分预算。失败作明确记录，不把0分自动解释为结构差，也不将未完成运行记为失败。

关键文件：`candidates.json`、各run的`effective_config.json`、`execution.json`、`initial_physics.json`、`learning_curve.jsonl`、`evaluations.json`、`report.json`。`random_initial.pth`记录随机初始权重；`best/latest/final.pth`保存训练成果。

启动：`python launch.py --num-envs 256 --seeds 2027,2028,2029 --steps 5000000`。运行结束由状态及报告确认，不能仅凭进程启动宣称收敛。

## 从零探索短流程的物理发现

三种形态均完成2个rollout的随机策略更新。基准和拇指加长变体最大单指力约5.7N、10.1N；拇指横移变体出现2次>25N事件，峰值381.5N，发生在回合约1.28秒、2.72秒，物体中心已移到支架附近（局部X约0.05m）。初始静态力约0.2N、关节越限约2.4e-7rad。数据支持“运动过程中出现强挤压/冲击”，但尚未证明具体接触对或求解器是否有错误。

不因暂时任务失败或探索过力直接淘汰该形态；完整验证继续记录过力次数、峰值和成功率，保留软惩罚。若训练后仍依赖过力，不能称为可靠收敛。新增完整计数不只依赖最多20条异常快照。

基准首个短流程在结果写出后出现app.close退出卡住，已确认checkpoint完成后结束该进程；后续入口使用明确退出，两个变体均正常结束。没有停止旧训练进程。
