# AX50 食指弹性、阻尼与软硬反馈排查 · 2026-11-28

## 范围

在 2026-11-27 的固定平面试件上复验。原物体、原抓取验收标准保持不变。本轮验证接触数值稳定性，不计抓取通过，也不是人体组织参数标定。

## 排查证据

- 基线恢复同一检查点，执行 0.4 mm 接近、2 mm 横向滑动、卸载；子步 0.125 ms，记录 5 ms 均值及每个子步原始量。记录弹性罚力、接触阻尼力、末节附着弹簧轴向反力、末节接触反馈、骨段速度。
- 新基线保持段平均法向力 0.263 N，5 ms 标准差 0.130 N；子步标准差 0.570 N。子步峰值中弹性罚力约占 74%，阻尼约占 26%。不能把这种波动解释成人体指腹刚度。
- 目标接触阻尼置零仅用于诊断：保持平均力 0.137 N，标准差仍 0.116 N，未解决。
- 加载后固定骨段：保持平均力 0.251 N，标准差 0.135 N，子步峰值 3.87 N。骨段速度为零、该末节直接软接触反馈为零时仍波动，排除其为唯一来源。此处不等于整只手所有软硬反馈均为零。
- 从相同固定姿态重新松弛，25/100 次迭代、普通/并行弹性求解、临时关闭软体自接触均未消除波动。自接触保持启用，没有永久禁碰。
- 子步记录发现同一顶点在顶点、边端点、面角点上重复生成约 7 条几乎相同的接触。例如全局粒子 6606 在一次快照中 7 条各约 0.14 N 的接触被重复计入；位置、法线、接触对象相同。对应粒子在最后求解阶段的力与最终读回值存在明显差距，不能把这类读回尖峰当可靠夹持力。两者计算阶段不同，这项仅作诊断，不是力守恒检验。
- 固定姿态下，仅合并重复端点记录，5 ms 力标准差从约 0.127 N 降至 0.00359 N，但仍有子步尖峰。
- 固定姿态下，仅将目标软接触罚刚度从有效 11250 降至 1125 N/m（非软组织弹性模量），保持原阻尼和摩擦：5 ms 力均值约 0.001549 N，标准差 0.0000117 N，子步峰值约 0.00197 N；最大软接触重叠约 0.0000451 mm。支持过硬且重复的离散接触造成数值跳变的判断。

## 已接入的修复

`contact_dedup.py`：仅对目标形状、重心权重 >0.99999 的端点重复记录去重；要求刚体局部接触位置相差 <1 μm，法线点积 >0.99999。保留不同位置、不同法线和不同顶点的接触。真正边内部、面内部接触保留。去重同时作用于求解、力读回和反馈，未做显示平滑。

`stable_soft_contact.py`：采用上述去重，目标软接触罚刚度设为 1125 N/m。软垫体积弹性参数、附着弹簧、接触阻尼和摩擦系数不变。罚刚度是数值接触参数，不声称匹配真人。物体尺寸、质量、自接触及原碰撞过滤不变。

额外试过的内部修正量缩小方案没有稳定解决问题，未纳入最终候选。

## 接入和复现

`PebbleRuntime` 已默认启用场景 07 的修复。其他场景和 AX50 原始包没有修改。当前基线采用的目标接触阻尼 0.5 在修复模块中显式保留。`stable_soft_contact.install()` 支持重复调用，不重复挂接。

旧运行逻辑备份：`scripts/nov20/ax50_pebble07/backups/pebble_runtime_pre_contact_fix_20261128.py`。复现本轮旧基线和各未修复诊断时，设置 `AX50_SOFT_CONTACT_FIX=0`；完整修复脚本显式安装修复，不作为旧基线使用。

去重专项测试通过：只去掉完全重合端点记录，不删除位置差异 2 μm、法线不同或顶点不同的记录。完整压入/滑动验证采用同一修复算法；默认入口另做 5 ms 集成检查（该检查本身不作为任务验收）。

详细统计：`coupling_fix_summary_1128.json`。修复限于本轮接触稳定性验证；人体材料校准、自由石子受载及抓取验收仍待验证。

## 解释边界

此前“约 0.3 N 保持力”含有大量数值振荡，不能据此认为真实夹持力已经足够，也不能用修复后更小的均值宣称承载能力下降。应基于修复后的稳定反力重新建立力—实际压陷关系，再做抓取。接近指令/骨段参考点位移不等于指腹材料压陷量。

每组为一次确定性运行；GPU 原子操作可造成接触排列和数值轨迹差异。诊断量中的末节附着力只是部分传力路径，不作为整手静力平衡证明。软硬双向通道保持连接，完整抓取和自由石子载荷验证尚未执行。

## 剩余波动

修复后末节附着弹簧轴向反力仍有毫牛顿级波动：0.4 mm 保持段标准差约 0.00113 N，全程绝对峰值约 0.00825 N。其幅值远低于旧接触尖峰，且固定骨段实验说明它不是旧尖峰的必要条件。本轮修复的是主要接触数值异常，不宣称所有软硬耦合振动已消失。下一步应在自由石子和更高真实载荷下检查传力与抓取。
