# AX50 07 拇指支撑与食指闭合验证 — 2026-11-27

结论：目标跟踪改善，但稳定对夹仍未通过，未执行2 mm探提。物体、质量、摩擦、软硬耦合参数及完整任务验收标准保持不变。

方法：同jitter_source_state_20261127.npz续测，恢复位置/速度/反馈，不恢复求解器warm-start。原手腕和其他手指目标保持；拇指以检查点实际关节位置为固定参考，仍受PD、力矩上限和碰撞反力影响，不是物理锁死。食指沿双指参考点连线闭合，累计未完成的目标，最大1 mm，低力时1 mm/s推进，高力时0.2 mm/s退让。食指平均力20 ms低通，0.05–0.2 N保持带。关节目标速度0.1 rad/s，力矩上限0.02 Nm。原始单侧力>2 N或刚体穿透>0.2 mm触发逐子步退让；穿透>0.8 mm终止。双指平均法向力连续100 ms均>0.005 N且无其他手接触，才启动2 mm探提。软体接触仍有效。
