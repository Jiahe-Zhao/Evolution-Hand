## 握持调试发现
1. 旧手纸面坐标不能直接照搬到AX50默认初态；新场景已上移手并重新布置纸面。
2. 原六轴腕的统一低增益力PD存在明显漂移；直接增大显式力PD出现非有限软体状态，试次已拒绝。
3. 准备握姿后调用solver.reset默认会恢复模型初态。早期试次首步状态不一致，产生异常力，不能作为资产模型结论。已改成 `reset(state, flags=0)` 并同步两状态缓冲、重置接触匹配。
4. 一致初态的锁腕握持仍失稳：当前试次约0.26秒笔根位移66.19 mm；加预紧的锁腕候选约0.20秒位移61.49 mm。它们均不是通过轨迹。初始接触方向与对向支撑尚未解决。
5. 多组IK候选只是几何候选；轴向、姿态与关节限位拟合不等于物理握持。`grip_candidate_*.json` 不代表通过。

## 2026-11-22 继续诊断（未通过）
本轮已接手额度耗尽后停止的远端 Kimi 结果。修正/确认以下问题，均不能据此宣称持握或书写通过：

2. `pads.npz.anchor_bone` 对应锚点集合，不能直接当作全软垫顶点的分区。当前改用资产自身的静止局部轴分区提取远端指腹。
