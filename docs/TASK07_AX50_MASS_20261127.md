# AX50 07 石子质量对照 — 2026-11-27

结论：加重明显减小侧移，但20/50/100 g均未完成抓取。原2.11 g资产和正式验收标准保留，不以加重对照计场景通过。

## 方法
使用当前coordinated_v2控制。只改变目标stone0/foot0质量，保持质量分布比例、形状、摩擦、托盘、邻石和控制参数。Newton实际质量20/50/100 g核对通过，单位质量惯量最大相对差1.24e-7；XML属性逐项检查只有上述两geom的mass变化。为质量敏感性诊断，不代表同体积天然石材的真实密度。

四组均从同一个2.11 g实验的jitter_source_state_20261127.npz恢复位置/速度/反馈；没有按各质量重新静置平衡，求解器warm-start未恢复。每组单次续测，不能视为全流程或统计成功率。2.11 g引用已完成coordinated_v2记录。相同控制策略会依接触力产生不同闭合轨迹，并非强制同一指尖轨迹。

比较共同的前0.4 s（均未开始提起）：水平位移相对每组首个5 ms记录点。双指连续100 ms平均法向力均>0.005 N、无其他手支撑才探提2 mm。此门槛只验证接触连续，并不保证夹持力足够承重。

50/100 g提起时食指失联，石子仍有托盘支撑，未通过2 mm探提。没有继续20 mm正式提起。所有记录状态有限，三档邻石相对原始场景初始位置最大位移均0.129 mm。

原生拇指刚体穿透峰值：20 g 0.105 mm，50 g 0.061 mm，100 g 0.066 mm。软反力峰值分别6.047/5.011/9.292 N，重物仍有接触尖峰，不能称动力学稳定性问题全部解决。

本轮支持“轻石子容易被推走”，但加重不是抓取成功的替代。50与100 g侧移差很小，进一步加重没有明显收益。保持原低力目标范围的本轮不能据失败判断重物不可抓；后续承重测试需要检查实际切向支撑力及接触方向，再决定夹持力目标。
