# 07 AX50 食指额外向内位移试验 — 2026-11-27

结论：三档均未建立持续双指夹持，未执行2 mm探提；完整场景仍未通过。原20 mm/0.3 s、邻石5 mm验收门槛不变。

## 方法
从相同jitter_source_state_20261127.npz恢复位置、速度和软硬反馈；求解器warm-start未恢复。每档独立一次，无重复统计，不能据此证明幅度与效果的单调关系。保持批准的上宽下窄石形、质量、摩擦及软硬接触；沿起始食指参考点指向石心方向，IK设置0.25/0.5/1.0 mm目标，50 ms后在300 ms内平滑追加到食指held target。保留原拇指控制、关节限位、0.02 Nm力矩上限、0.25 rad/s目标速度限值，以及0.4 N/0.2 mm触发退让。保留soft kd=0.5候选，不代表已校准人体组织。

实际位移使用食指末节附着参考点，不是软皮表面压缩量。额外关节目标仍受原控制器退让和q±0.003 rad限制；本实验不是强制手指实际内移指定毫米数。保持末50 ms的每个5 ms采样窗均需双指平均力>0.005 N且无其他手部支撑才探提；三档都未满足。

1 mm档实际内移峰值0.276 mm、最终0.151 mm；石子同轴位移0.936 mm，因此指尖相对石心沿该方向反而远离0.785 mm。它反映失去持续夹持，不能当成几何表面间隙或归因于单一接触参数。

当前解释：增加位置目标被限力、接触退让及实际动力学响应共同改变，石子还发生侧移。尚不能据单轮归因于Newton精度或物体几何。下一步优先诊断拇指支撑/食指退让的协调，避免无约束提高闭合量。

## 失稳原因复核
对三档已记录轨迹重新投影到初始两指参考点连线（区别于上一节食指指向石心轴）：双指持续力>0.005 N最长分别20/25/40 ms；拇指单独有力的5 ms采样比例49%/58%/43%，食指单独有力均0%。主要接触丢失侧是食指，不支持直接断言拇指先失联。

1 mm档两指参考间距最终只缩短0.111 mm，而石子沿两指连线移动0.436 mm。此前0.936 mm是在食指到石心方向的投影，两者轴不同，不应混用。参考点间距不是软表面实际间隙。

控制代码已核实：接触锁存后忽略常规command，使用held；瞬时力>0.4 N或刚体深度>0.2 mm时held按0.5 rad/s退让，低力<0.06 N且深度<0.05 mm时仅0.005 rad/s补进。内部速率比100，最终target另受0.25 rad/s限制，不能声称指尖实际退让速度比100。每子步held还裁到实际q±0.003 rad，追加目标可能被裁掉，无笛卡尔剩余位移积分补偿。两指独立调节，没有对夹中心/间距联合稳定。

因此确认存在“指令不等于实际夹紧”和食指间歇失联；快速退让/慢恢复是代码支持的主要嫌疑机制。此前软硬接触脉冲仍可能触发该机制。现有5 ms平均力日志没有逐子步退让触发计数，不能证明每次失联均由退让造成，也不能排除接触求解贡献。尚不能宣称Newton精度不足或手模型本身是唯一根因。

建议下一轮保持物体/接触不变，增加逐子步退让原因与held/actual误差记录；用保留未完成位移的夹距控制、力反馈滞回和双指协调做单变量对照。穿透保护保留。证据：outputs/nov20/ax50_pebble07/inward_cause_audit.json。
